# 1일 1알고리즘 스터디

매일 꾸준히 한 문제 이상 풀며 문제 해결 습관을 만드는 스터디입니다.  
문제 사이트, 난이도, 알고리즘, 프로그래밍 언어는 자유입니다.

## 스터디 규칙

1. 매일 알고리즘 문제를 **최소 1문제** 풉니다.
2. 풀이 코드는 당일 저장소에 커밋합니다.
3. 다른 사람의 풀이를 참고했다면, 이해한 뒤 자신의 방식으로 다시 작성합니다.
4. 정답 코드만 올리기보다 핵심 아이디어와 시간 복잡도를 간단히 기록합니다.
5. 부득이하게 참여하지 못한 날은 스터디원에게 미리 공유합니다.

## 문제 선정

- 문제는 자유롭게 선택합니다.
- 백준, 프로그래머스, LeetCode, SWEA 등 어떤 플랫폼이든 가능합니다.
- 자신의 실력보다 조금 어려운 문제에 꾸준히 도전하는 것을 권장합니다.
- 이미 풀었던 문제도 새로운 방식으로 다시 풀었다면 인정합니다.

## 폴더 구조

각자 자신의 이름 또는 GitHub 아이디 폴더를 만들고, 연도와 월별로 풀이를 정리합니다.

```text
algo_study/
├── README.md
└── solutions/
    ├── kim/
    │   └── 2026/
    │       ├── 11/
    │       │   ├── 2026-11-21_boj_1000.py
    │       │   └── 2026-11-22_programmers_두-수의-합.java
    │       └── 12/
    └── lee/
        └── 2026/
            └── 11/
                └── 2026-11-21_leetcode_1.js
```

파일명은 다음 형식을 권장합니다.

```text
YYYY-MM-DD_플랫폼_문제번호 또는 문제명.확장자
```

예시:

```text
2026-11-21_boj_1000.py
2026-11-21_programmers_두-수의-합.java
2026-11-21_leetcode_1.cpp
```

## 풀이 작성 방식

코드 상단에 아래 내용을 주석으로 간단히 남겨 주세요.

```text
문제 링크:
핵심 아이디어:
시간 복잡도:
```

예시:

```python
# 문제 링크: https://www.acmicpc.net/problem/1000
# 핵심 아이디어: 두 정수를 입력받아 더한다.
# 시간 복잡도: O(1)
```

## 커밋 메시지

```text
solve: [플랫폼] 문제번호 문제명
```

예시:

```text
solve: [BOJ] 1000 A+B
solve: [Programmers] 두 수의 합
solve: [LeetCode] 1 Two Sum
```

여러 문제를 한 번에 올릴 때는 다음과 같이 작성할 수 있습니다.

```text
solve: 2026-11-21 알고리즘 문제 풀이
```

## 참여 방법

1. `solutions/본인-이름` 폴더를 생성합니다.
2. 문제를 풀고 정해진 구조에 맞춰 풀이 파일을 추가합니다.
3. 커밋 후 저장소에 푸시합니다.
4. 다른 스터디원의 풀이도 자유롭게 리뷰하고 의견을 나눕니다.

하루 한 문제, 꾸준함으로 실력을 쌓아 봅시다! 🚀
